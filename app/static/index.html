Instruqt pre-flight check

Check your access to the webinar content.

This Instruqt pre-flight challenge helps validate that you are able to access the webinar content.

If you are not able to access the content, we suggest joining from a personal machine rather than a work machine.

How this works

  • There are 4 short steps. Each one shows you something and asks whether you can see it. It takes about two minutes.
  • Please use the same computer, browser and network you plan to use for the webinar.
  • You do not need to install anything or type any commands.
  • The tabs along the top of the Instruqt screen (Launchpad, Terminal, Editor, Browser, Temporal UI) are different views of the same environment. Stay on Launchpad unless a step tells you to open another tab.

Step 1 of 4 · Browser

Can you see the image below?

You should see a small illustrated space explorer named Ziggy.

A blank frame usually means a work network or browser policy is blocking the page. Open the Browser tab at the top of the screen to try again at full size. If it is still blank, continue to the next step. Your report will list this as a problem to share with your organizer.

Step 2 of 4 · Editor

Can you see the code editor below?

You should see a file list on the left and a welcome file open on the right.

Open the Editor tab at the top of the screen to try it at full size. If it works there, return to Launchpad and answer yes. If it stays blank or keeps reconnecting, continue to the next step. Your IT team may need to allow secure WebSockets and Instruqt sandbox access.

Step 3 of 4 · Terminal

Check the terminal tab.

The terminal is a separate tab, so this step takes you away from Launchpad for a moment.

  1. Click the Terminal tab at the top of the Instruqt screen.
  2. Look for the text ZIGGY ONLINE and a clock that changes every second. You do not need to type anything.
  3. Click the Launchpad tab to come back here and answer below.

Did the terminal show a ticking clock?

If the terminal stays blank or the clock stops, the live connection may be blocked. Your IT team may need to allow wss://*.env.play.instruqt.com on port 443. Continue to the next step and share the report with your organizer.

Step 4 of 4 · Temporal UI

Can you see the Temporal UI below?

You should see a navigation menu and a Workflows page. An empty list is expected.

Open the Temporal UI tab at the top of the screen to try it at full size. Answer yes only if you see the application itself, not a login page, error or loading spinner. If it fails there too, continue and share the report with your organizer.

Results

All done.

    You are ready

    Click Check at the bottom right of the Instruqt screen to finish. This confirms what you could see just now. You will do the workshop exercises during the webinar.

    Some content was not accessible
